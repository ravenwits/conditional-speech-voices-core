# Reports and suggestions

Use the issue form for bugs. Include versions, the selected voice, steps to reproduce, relevant mods and a debug report. Explain when a report cannot be generated. English and Turkish are welcome.

PolyForm Strict does not grant permission to modify or redistribute this code. Ask the maintainer for written permission before preparing a code contribution. Opening an issue does not grant that permission.

Do not attach API keys, account tokens, complete user folders or unrelated private logs.
