# Workshop artwork

The square and wide templates use Studio's two-line Cal Sans wordmark and its
dark palette with Spotify green. The source font and its OFL are included with
the Studio frontend. Country flags come from the public-domain
[Flagpedia 160 px archive](https://flagpedia.net/download/images).

The Workshop uploader reads the square 256 × 256 preview. Studio also provides a
1280 × 720 image for sharing. Languages with a known locale get its flag.
Multinational languages use a representative country, and languages without a
mapped flag get a neutral globe.
