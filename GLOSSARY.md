# Conditional Speech Voices

A voice pack supplies recorded reactions for the survivor. Core decides when a reaction can play.

## Language

**Recording slot**

A place in the Core catalogue for a specific reaction and delivery. A slot can have a caption before it has audio.

**Recording brief**

The gameplay conditions and performance direction for a recording slot. It includes who can use the line, when it plays and how to voice it.

**Active take**

The audio currently selected for a recording slot in a voice project. Approval and measurements belong to that take.

**Required gap**

A required situation or native event for which the project has no approved take that qualifies. One take can cover more than one gap.
